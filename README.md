
# My Portfolio

My personal portfolio website built using React to showcase my projects, technical skills, education, experience, and achievements.

## Key Features
- Responsive design for desktop and mobile devices
- Modern cosmic theme with glassmorphism UI
- Smooth animations using Framer Motion
- Dedicated sections for About, Skills, Projects, Experience, Education, and Achievements
- Project cards with technology details and GitHub links
- Resume access and download
- Contact information and social media links
- Interactive mobile navigation
- Painting and personal interests section

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Framer Motion
- Lucide React
- Vite

## Run Locally

```bash
npm install
npm run dev
```
